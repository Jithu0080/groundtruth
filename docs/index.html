Groundtruth
ExploreResultsSource on GitHub

A reranker found the right passage for 68% of legal questions, up from 51%.

Groundtruth is an evaluation harness for a legal research assistant. It measures whether a change to the search system actually helps, using 104 human-reviewed questions over 700 Supreme Court of India judgments from 2023.

The baseline searches by meaning alone. Production adds keyword search and a reranker that reads each candidate passage against the question. The gain is +16 points of recall@10 (95% confidence interval +4 to +28) while sending half as much text to the language model.

    What the numbers showed

    The reranker does the work. The baseline already had 77% of answers in its top 50 but only 51% in its top 10. Rereading those 50 against the question recovered most of the gap.

    Keyword search was the weakest retriever, because the questions were written in plain language rather than copied from the judgments. An evaluation set that copies wording would flatter it.

    Big passages inflate recall. 1,600-character passages score 0.622 but send four times as much text. Recall has to be read next to context size.

    Keyword search adds nothing once there is a reranker. The ablation is slightly better without it, within noise. It was measured on test, so it is a candidate for the next version, not a reason to switch.

    CauseQuestions
    The answer was retrieved from elsewhere in the same judgment, for example a headnote that repeats the body10
    Near-identical text exists in another judgment, including one judgment stored twice7
    The question's wording never connected to the legal term, such as "approbate and reprobate"4

    Only 4 of 74 test questions are genuine vocabulary misses. The right judgment is in the top 10 for about 85% of questions, so the strict one-passage labels under-state the system.
